# SHAPE-project-

## SOIL MOISTURE AND LIGHT INTENSITY METER A TELEMETRY SYSTEM THROUGH WI-FI NETWORK AND MOBILE PHONE

# Link to sensor application:
https://eden-self-seven.vercel.app/ 

## Brief description: 

The device consists of an ESP32 microcontroller which includes
WIFI capability, a capacitive soil moisture sensor, an LDR light sensor and a
battery.

The whole assembly and the firmware was designed and constructed in 2025 at the Columbia University within a team project. 
The moisture sensor was selected to be capacitive, instead of the more common resistive type, because it is far more corrosion resistant.
The device’s sensors (soil moisture and light intensity) are read by the ESP32
software and are transmitted periodically to a n android mobile via an application which was programmed by the team.
This concept can be turned to an IoT system by incorporating commands to
peripherals (e.g. relays) which will enable certain actions like plant watering
during certain phases of the day etc.
The whole construction is inside a neat plastic enclosure and is easy to use as a
soil moisture and light intensity measurement device
